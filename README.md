A simple web app to track daily expenses. Add an expense, see the total, and delete items. Your data is saved in the browser, so it stays after a refresh.

## Features

- Add an expense with a description, amount, and category
- See the running total
- Delete an expense
- Data saved with localStorage

## Built With

- HTML
- CSS
- JavaScript

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/ibnAwsan/expense-tracker.git
   ```
2. Open the folder:
   ```bash
   cd expense-tracker
   ```
3. Open `index.html` in your browser.
